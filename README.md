# Library Management System

A short console-based Java project for the CSE2006 Programming in Java course.

## Requirements

- Java JDK
- VS Code
- Java Extension Pack (recommended)

No MySQL, XAMPP, Maven, Gradle, or other application is required.

## Run in VS Code

Open this folder in VS Code and open the terminal.

```bash
javac *.java
java Main
```

## Features

1. Add Book
2. View Books
3. Search Book
4. Add Member
5. View Members
6. Issue Book
7. Return Book
8. Show Issued Books
9. Save & Exit

## Java Concepts Demonstrated

- Classes and Objects
- Constructors
- Encapsulation
- Inheritance
- Method Overriding / Polymorphism
- ArrayList
- Exception Handling
- File I/O
- Loops and switch

## Storage

The program uses a simple `library.txt` file to save books and members.
This avoids the need for a separate database.
